# Report security issues

Report undisclosed vulnerabilities privately to the repository owner.
If the future repository enables GitHub's private vulnerability reports, use
that interface. Keep exploit details and private input images out of public
issues.

Include these details in your report:

- The version and operating system.
- Steps to reproduce the issue with a synthetic input.
- The expected security boundary.
- The actual behavior.

Exclude sensitive images and filesystem contents from attachments.

The [security model](docs/security.md) describes limits and remaining risks.
This local development version did not undergo an external security audit.
