# Third-party notices

The Go executable uses the modules in the following table. This repository
preserves their original license notices. The Go standard library uses the Go
BSD license.

FFmpeg, VHS, Node.js, OpenSpec, and Quint are optional external or development
tools. The runtime binary does not include them. Their own licenses apply.

The palette atlas and artwork labels use the Go font family from `golang.org/x/image`.
The [font license](docs/assets/GO-FONTS-LICENSE.txt) accompanies the generated
artwork and the standalone showcase. The [palette library](docs/palettes.md)
records sources for published colors and historical display approximations.

The banner and atlas generators use [Source Serif 4](https://github.com/adobe-fonts/source-serif)
from Adobe. Its TrueType font and original [SIL Open Font License
notice](docs/assets/fonts/SOURCE-SERIF-LICENSE.md) accompany the generators.
The generated banner contains outlined glyphs and loads no external font.

The standalone website bundles three font families under the SIL Open Font
License 1.1. It loads these fonts from local files:
